SINERGYCHAIN Growth OS V7 source bundle.

The archive in this directory contains the complete reproducible source tree used by CI and GitHub Pages. It intentionally excludes runtime secrets, logs, node_modules, reports and populated databases.

Unpack locally:

```bash
mkdir sinergychain-v7
cd sinergychain-v7
tar -xzf ../SINERGYCHAIN_GROWTH_OS_V7_SOURCE.tar.gz
npm run check
npm start
```
